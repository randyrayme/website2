## GitHub Pages deployment
1. Open your website's existing GitHub repository.
2. Back up the existing files or create a branch before replacing anything.
3. Upload `index.html`, `styles.css`, `script.js`, and the complete `assets/` folder to the repository root.
4. Commit changes; GitHub Pages will publish according to the repository's existing Pages settings.

**Do not publish until you approve the preview.** Verify contact information, licensing disclosures, links, and mortgage compliance before going live.

The standalone preview is provided separately; it embeds all images in one HTML file and does not require the assets folder.
